# Carts (local only)

Put your own Game Boy / Game Boy Color ROM dumps here. **This directory is not a ROM warehouse and is not git-tracked.**

Typical names the ignored commercial-smoke harness looks for (first match wins per title):

| Title | Typical file |
|-------|----------------|
| Tetris | `tetris.gb` |
| Final Fantasy Adventure | `final-fantasy-adventure.gb` |
| Kirby's Pinball Land | `kirbys-pinball-land.gb` |
| Pokémon Red | `pokemon_red-version__usa-eu.gb` |
| Pokémon Blue | `pokemon_blue-version.gb` |
| Pokémon Yellow | `pokemon_yellow-version.gb` |
| Link's Awakening | `legend-of-zelda_links-awakening__usa-eu.gb` |
| Super Mario Land 2 | `super-mario-land-2_6-golden-coins__usa-eu.gb` |
| Wario Land | `wario-land_super-mario-land-3__world.gb` |

You can also point harnesses at another folder with `GRAYCART_CARTS`.

Conformance fixtures (Blargg / Mooneye) live under `tests/fixtures/`.
